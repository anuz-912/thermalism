# Thermalism

A C++ numerical solver and Python visualizer for 2D transient and steady-state heat conduction across a 10 cm square plate (100x100 grid). The solver computes time-dependent diffusion using Forward-Time Central-Space (FTCS), solves the steady-state equilibrium via Gauss-Seidel with Successive Over-Relaxation (SOR), exports time-step snapshots to CSV, and triggers `visualizer.py` for plotting.

## Features

* **Dual Numerical Solvers:**
  * **Transient Analysis:** Explicit FTCS scheme with automatic Courant-Friedrichs-Lewy (CFL) time-step scaling (`dt = 0.9 * dt_max`).
  * **Steady-State Analysis:** Gauss-Seidel with SOR ($\omega = 1.85$) to verify final thermal equilibrium and compute maximum deviation against the transient solution.
* **Time-Step Snapshots:** Automatically captures temperature distributions at scaled intervals of the thermal time constant $\tau$ ($0, 0.1\tau, 0.5\tau, 1.0\tau, 2.0\tau, 4.0\tau$) plus final convergence.
* **Material Presets:**
  1. Aluminium
  2. Copper
  3. Iron
  4. Stainless Steel
  5. Brass
  6. Custom (user-defined thermal conductivity $k$, density $\rho$, and specific heat $c_p$)
* **Automated Visualization:** Exports grid coordinates, final transient/steady-state temperatures, and intermediate time snapshots to `.csv`, then launches `visualizer.py` to generate and open the `.png` plot

## Setup & Installation

1. **Install Python dependencies:**
   ```bash
   pip install numpy pandas matplotlib
   ```

2. **Compile the C++ solver:**
   ```bash
   g++ -O3 thermalsim.cpp -o thermalism
   ```

## Usage

1. **Run the simulator:**
   ```bash
   ./thermalism
   ```
   *(On Windows, run `thermalism.exe`)*

2. **Follow the prompts:**
   * Enter outer boundary temperatures (`TOP BOTTOM LEFT RIGHT`)
   * Enter the initial uniform plate temperature

3. **Standalone plotting (optional):**
   ```bash
   python visualizer.py your_output.csv
   ```

## Output Files

* `<filename>.csv`: Grid data with columns `x, y, T_transient, T_steady` followed by timestamped snapshot columns (`T@<time>`)
* `<filename>.png`: Rendered thermal distribution plot generated by `visualizer.py`
