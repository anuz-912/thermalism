# Thermalism

A C++ numerical solver and Python visualizer for 2D transient and steady-state heat conduction across a 10 cm square plate (100x100 grid)[cite: 1]. The solver computes time-dependent diffusion using Forward-Time Central-Space (FTCS), solves the steady-state equilibrium via Gauss-Seidel with Successive Over-Relaxation (SOR), exports time-step snapshots to CSV, and triggers `visualizer.py` for plotting[cite: 1].

## Features

* **Dual Numerical Solvers:**
  * **Transient Analysis:** Explicit FTCS scheme with automatic Courant-Friedrichs-Lewy (CFL) time-step scaling (`dt = 0.9 * dt_max`)[cite: 1].
  * **Steady-State Analysis:** Gauss-Seidel with SOR ($\omega = 1.85$) to verify final thermal equilibrium and compute maximum deviation against the transient solution[cite: 1].
* **Time-Step Snapshots:** Automatically captures temperature distributions at scaled intervals of the thermal time constant $\tau$ ($0, 0.1\tau, 0.5\tau, 1.0\tau, 2.0\tau, 4.0\tau$) plus final convergence[cite: 1].
* **Material Presets:**[cite: 1]
  1. Aluminium[cite: 1]
  2. Copper[cite: 1]
  3. Iron[cite: 1]
  4. Stainless Steel[cite: 1]
  5. Brass[cite: 1]
  6. Custom (user-defined thermal conductivity $k$, density $\rho$, and specific heat $c_p$)[cite: 1]
* **Automated Visualization:** Exports grid coordinates, final transient/steady-state temperatures, and intermediate time snapshots to `.csv`, then launches `visualizer.py` to generate and open the `.png` plot[cite: 1].

## Setup & Installation

1. **Install Python dependencies:**
   ```bash
   pip install numpy pandas matplotlib
   ```

2. **Compile the C++ solver:**
   ```bash
   g++ -O3 thermalsim.cpp -o thermalism
   ```

## Usage

1. **Run the simulator:**
   ```bash
   ./thermalism
   ```
   *(On Windows, run `thermalism.exe`)*

2. **Follow the prompts:**
   * Enter outer boundary temperatures (`TOP BOTTOM LEFT RIGHT`)[cite: 1]
   * Enter the initial uniform plate temperature[cite: 1]
   * Select a plate material preset (or enter custom properties)[cite: 1]
   * Enter an output filename (without `.csv`)[cite: 1]

3. **Standalone plotting (optional):**
   ```bash
   python visualizer.py your_output.csv
   ```

## Output Files

* `<filename>.csv`: Grid data with columns `x, y, T_transient, T_steady` followed by timestamped snapshot columns (`T@<time>`)[cite: 1].
* `<filename>.png`: Rendered thermal distribution plot generated by `visualizer.py`[cite: 1].
